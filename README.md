## What Brewtimer Is

Brewtimer is made for pour-over coffee brewing and centers on accessible timing support in a light web-based package. It gives coffee brewers an uncomplicated way to stay on track with brewing steps without adding a bulky application or a complicated setup process.

Since the project is built in HTML, it is straightforward to host and open from a browser. That makes it a solid choice for home brewers, coffee fans, and anyone looking for a no-frills pour-over timer.

## How to Use It

Launch Brewtimer in a modern browser and start your brewing session from the main timer screen.

Typical workflow:
1. Start the timer before your first pour.
2. Use the timing support to track brew stages.
3. Follow your pour-over routine while watching elapsed time.
4. Reset the session when the brew is complete.

If you host the project yourself, keep the HTML file and related assets together in the same folder structure.
